Slide Planner uses Claude to read your old decks and write new lessons. Add a Claude API key once to switch it on. If someone set this up for you, they can add it in Settings instead.

Can I use my Claude Pro or Max subscription?
Not in other apps. Anthropic only allows subscription sign-in inside its own apps, so apps like this one connect with an API key. Usage is billed to whoever owns the key.
